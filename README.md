### 📌 개요

- **구현 기간**: 2022.11.12 ~ 2022.11.13
- **기술 스택**: JavaScript, Vue.js
 
GDSC in BUSAN과 부경대학교 Linc 3.0에서 주최한 **제 1회 놀러와요 해커톤** 참가작입니다.

### 🎯 목적

> 네컷 사진 촬영 과정에 가벼운 즐거움을 주는 포즈 추천 애플리케이션

네컷 사진 촬영이 일상적인 문화로 자리 잡았지만, 막상 사진을 찍을 때마다 비슷한 포즈를 반복하게 되는 경우가 많습니다.

본 프로젝트는 사용자가 페이지에 접속하는 즉시
네컷 사진 촬영에 활용할 수 있는 다양한 포즈를 랜덤으로 추천함으로써,
보다 자연스럽고 즐거운 사진 촬영 경험을 제공하기 위해 제작되었습니다.

단순하고 직관적인 UI로, 짧은 사진 촬영 준비 시간동안
바로 포즈를 추천받아 사용할 수 있도록 화면을 구성했습니다.
