### 📌 개요

- **구현 기간**: 2022.11.12 ~ 2022.11.13
- **기술 스택**: JavaScript, Vue.js

> 촬영 직전의 짧은 순간, 선택의 고민 대신 즐거움을 더해주는 포즈 추천 애플리케이션
 
GDSC in BUSAN과 부경대학교 Linc 3.0에서 주최한 **제1회 놀러와요 해커톤** 참가작입니다.

### 🎯 목적

네 컷 사진 촬영이 일상적인 문화로 자리 잡았지만, 막상 사진을 찍을 때마다 비슷한 포즈를 반복하게 되는 경우가 많습니다.

본 프로젝트는 사용자가 페이지에 접속하는 순간
네 컷 사진 촬영에 활용할 수 있는 다양한 포즈를 랜덤으로 추천함으로써,
촬영 전의 어색한 시간을 줄이고 자연스럽고 즐거운 촬영 경험을 제공하고자 제작되었습니다.

단순하고 직관적인 UI를 구성하여 짧은 촬영 준비 시간 안에서도 부담 없이 포즈를 확인하고 선택할 수 있도록 구성했습니다.
